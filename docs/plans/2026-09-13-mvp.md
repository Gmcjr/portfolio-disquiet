# MVP build plan — Disquiet

**Status:** Not started

Sequenced, dependency-ordered. Each phase should leave the repo in a working, committable
state. The walking skeleton (phases 1–4) exists to prove the two seams most likely to hide a
surprise — the content pipeline and the form-to-inbox path — before any visual polish or a
second case study gets built on top of them.

## Phase 1 — Repo and config

1. `git init`; `.gitignore`, `.editorconfig`, `LICENSE` (MIT), this repo's `.claude/` (done),
   `README.md` (done).
2. Hand-write `package.json`: `private: true`, `type: "module"`, `engines.node: "24.x"`, no
   `packageManager` field. Scripts: `dev`, `build`, `preview`, `typecheck`, `lint`,
   `lint:fix`, `format`, `format:check`, `depcruise`, `test`, `prepare` (`lefthook install`).
3. Commit `.nvmrc` (`24`).
4. Install dependencies (exact-pinned — verify current versions against the registry at this
   point, don't trust a stale number): `astro`, `@astrojs/mdx`, `@astrojs/sitemap`,
   `@tailwindcss/vite`, `tailwindcss`, `zod`, `resend`. Dev: `@astrojs/check`, `typescript`
   (6.x — verify `typescript-eslint` and `@astrojs/check`'s peer ranges before taking a newer
   major), `eslint`, `typescript-eslint`, `eslint-plugin-astro`, `eslint-config-prettier`,
   `prettier`, `prettier-plugin-astro`, `dependency-cruiser`, `lefthook`, `vitest`, a DOM env
   for the one form test (`jsdom` or `happy-dom`), `@lhci/cli`, `@axe-core/cli`.
5. Commit `bun.lock` — confirm it's the text format, not binary.
6. `tsconfig.json` extending `astro/tsconfigs/strict`, plus `verbatimModuleSyntax`,
   `noUncheckedIndexedAccess`, path alias `@/* → src/*`.
7. `src/config/site.ts` — placeholder domain/name, nav model (all four sections listed, only
   `work`/`about`/`contact` `enabled`), GoatCounter endpoint, public contact email constant.
8. `astro.config.ts`, importing `SITE_URL` from step 7. `vite.plugins: [tailwindcss()]`. No
   `@astrojs/tailwind`.
9. `src/styles/global.css` — `@import "tailwindcss"`, empty `@theme` block to start.
10. `src/layouts/BaseLayout.astro`, `src/pages/index.astro` (minimal), `src/pages/404.astro`.

## Phase 2 — Quality rails

11. ESLint flat config, Prettier config, `.dependency-cruiser.cjs` (rules per ARCHITECTURE.md
    §4/§10, ADR-0003) — run both, expect clean on the skeleton.
12. `lefthook.yml` (pre-commit: format + lint on staged files; pre-push: typecheck +
    `depcruise`). Install hooks, test with a commit.
13. `.env.example` (keys only, no values); create a local `.env` from it.
14. Vitest config (`getViteConfig()` from `astro/config`, so `astro:content` and the `@/*`
    alias resolve).
15. `.github/workflows/ci.yml` — install, lint, format:check, typecheck, depcruise, grep guards
    (domain string confined to `site.ts`; content folder names kebab-case), test, build, bundle
    size check, axe, Lighthouse-CI. All blocking. Require it in branch protection.

## Phase 3 — Content pipeline seam

16. `src/content.config.ts` — all four collections (`work`, `writing`, `music`, `art`), base
    schema plus per-type extensions (ADR-0002). `generateId` derives the slug from the folder
    name.
17. `src/lib/content/index.ts` — `getPublished`, `getAllWork`, `getWorkBySlug`,
    `getFeaturedWork`, all taking an explicit `includeDrafts` parameter (no hidden env read
    inside the query functions).
18. One real case study: `src/content/work/<slug>/index.mdx` plus its cover image.
19. `src/pages/work/index.astro`, `src/pages/work/[...slug].astro` with `getStaticPaths`.
    Build and confirm the case study renders as static HTML.

## Phase 4 — Form seam (deploy to production before moving on)

20. `src/lib/contact-schema.ts` — the shared Zod schema (ADR-0004), CR/LF-stripped `name`.
21. `api/_env.ts` — validates `RESEND_API_KEY`/`CONTACT_TO`/`CONTACT_FROM` at module load.
22. `api/contact.ts` — `handleContact(req, deps)` per the pipeline in ADR-0004, `deps` includes
    `timeoutMs` and a `log` sink (not just `sendEmail`/`now`) so the timeout branch and every
    log assertion are unit-testable without a real 10-second wait.
23. Unit tests for every row of ADR-0004's response table, plus the schema and content-query
    tests from phase 3.
24. `src/components/contact/` — a DOM-free reducer plus a `createContactForm(rootEl, deps)`
    factory; the bundled `<script>` in `contact/index.astro` is a two-line caller. Static
    `mailto:` fallback and `<noscript>` block always present outside the script.
25. Push to GitHub (public repo), import to Vercel, set **production** env vars, set
    **preview**-scoped env vars per `docs/RUNBOOK.md`.
26. Deploy to production. Run the post-deploy smoke test (`docs/RUNBOOK.md`) — this is the
    point where an actual email must arrive. Don't proceed to phase 5 until it does.

## Phase 5 — Security surface

27. `vercel.json` — security headers including CSP (ARCHITECTURE.md §7), plus a routing rule
    for the reserved sections' 404 behavior if step 26 revealed Vercel serves a soft-200.
28. `src/pages/privacy/index.astro` — the disclosure covering GoatCounter and Resend
    (STYLEGUIDE.md's microcopy is the contact-form-specific piece; this page is broader).
29. CI grep guard confirming no secret value or `RESEND_API_KEY` string appears under
    `src/`/`public/`/`dist/`. Enable GitHub secret-scanning push protection on the repo.
30. `public/robots.txt`, `favicon.svg` + fallbacks, `og-default.png` (needs the user's real
    name/role — see `CONTEXT.md`'s open items).

## Phase 6 — Design system and remaining content

31. Fill in the real `@theme` token values (STYLEGUIDE.md), fonts, the wavering-line component,
    dark-mode toggle, view transitions on the work-list → case-study path.
32. Remaining case studies. `about/index.astro` (or `src/content/about.mdx` — decide when
    written; either is fine).
33. Manual WCAG 2.2 AA pass (the checklist in `ARCHITECTURE.md` §8 / STYLEGUIDE.md) — keyboard
    navigation, focus-not-obscured after a view transition, reduced-motion, 200% zoom,
    placeholder/disabled contrast in both themes.
34. Final launch checklist (ARCHITECTURE.md §8, `docs/RUNBOOK.md`): perf gate green, a11y gate
    green, real domain DNS-verified for Resend, `v1.0.0` tagged.
