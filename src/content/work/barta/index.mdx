- Implemented content moderation, running asynchronously through the Google Gemini API on a shared job-queue architecture
- Designed a polymorphic Report/Appeal system in Prisma, optimizing database structure with a single model
- Extended theme support for dark mode and accessibility modes across 20+ components
- Wrote the platform's Code of Conduct and README
